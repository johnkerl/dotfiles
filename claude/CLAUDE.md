# Global preferences

- When the user runs a shell command themselves (via the `!` prefix, shown as `<bash-input>`/`<bash-stdout>` in the transcript), do not comment on the command or its output. Note: the harness forces a visible reply every turn, so true silence isn't possible via `!` — if a reply is unavoidable, keep it to the bare minimum rather than analysis or commentary. The user's actual workaround for full silence is suspending Claude Code (Ctrl-Z), running the command directly in the shell, then `fg` back in.
